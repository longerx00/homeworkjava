В этом проекте я написал консольную программу на Java для работы с матрицами, которые состоят из комплексных чисел. Всю работу разделил на несколько классов. Сначала сделал класс CompleksnieChisla — он отвечает за сами числа с вещественной и мнимой частью: умеет их складывать, вычитать, умножать, делить и выводить на экран в привычном виде вроде «2 + 3i». Затем написал класс Matritsa, где матрицы хранятся как двумерные массивы этих чисел. В нём я запрограммировал все нужные действия: сложение матриц, их умножение строка на столбец, транспонирование (поворот строк в столбцы), поиск определителя методом Гаусса и деление одной матрицы на другую (через умножение на обратную матрицу). Чтобы программа не вылетала при неправильных размерах или делении на ноль, сделал свой класс ошибки MatritsaExeprion. В главном классе Main сделал простое текстовое меню: пользователь выбирает действие от 1 до 5, вводит количество строк и столбцов, построчно забивает числа (сначала реальную часть, потом мнимую) и сразу видит результат на экране.
